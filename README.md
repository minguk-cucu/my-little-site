# 나의 루틴 트래커

로그인, 데이터베이스, 외부 API 없이 사용하는 한 페이지 루틴 트래커입니다. Vanilla JavaScript와 Vite로 개발하며, Node.js 22.12 이상을 권장합니다.

## 실행

이 폴더에서 터미널을 열고 최초 한 번 `npm install`을 실행하세요. 이후 `npm run dev`를 실행한 다음 브라우저에서 http://localhost:3000 에 접속하세요. 기존 명령인 `npm start`도 사용할 수 있습니다. 종료하려면 터미널에서 Ctrl+C를 누르세요.

Vite 개발 서버는 파일을 수정하면 화면에 변경 사항을 반영합니다. 기존 기록을 유지하려면 계속 같은 브라우저에서 http://localhost:3000 을 사용하세요. 포트가 사용 중이면 기존 서버를 종료한 후 다시 실행하세요.

## 빌드

- `npm run build`: 배포용 정적 파일을 `dist/` 폴더에 생성합니다.
- `npm run preview`: 빌드 결과를 http://localhost:4173 에서 확인합니다. 이 주소의 브라우저 저장 공간은 개발 서버와 별개입니다.

## 사용

- **새 루틴 만들기**에서 이름, 색상, 반복 주기, 시작일과 종료일을 선택하세요. 주기는 매일, 특정 요일(복수 선택), 1~365일 간격을 지원합니다. 종료일을 비우면 계속 반복합니다.
- 시작일과 종료일을 포함한 기간 내에서 예정된 날짜에만 루틴이 표시됩니다. 며칠 간격은 시작일 기준입니다. 기존 루틴은 등록일부터 매일 반복하는 설정과 기록을 유지합니다.
- 캘린더 날짜를 선택하고 아래에서 완료 여부와 메모를 입력하세요. 미래 날짜는 조회만 가능합니다.
- 캘린더의 선택 상자로 특정 루틴의 달성을 확인할 수 있습니다.
- 연속 기록은 예정된 수행일을 연속으로 완료한 횟수입니다. 쉬는 날은 기록을 끊지 않으며, 오늘의 미완료는 아직 실패로 계산하지 않습니다. 지난 수행일을 놓치면 연속 기록이 끊깁니다. 아래 기록은 선택한 날짜 기준입니다. 종료된 루틴은 마지막 연속 기록을 보존하며 상단의 현재 연속 기록에서는 제외됩니다.
- 루틴 옆 ×로 루틴과 해당 기록을 삭제할 수 있습니다. 삭제 전 확인 창이 표시됩니다.

데이터는 현재 브라우저의 localStorage에 자동 저장됩니다. 같은 브라우저와 주소를 계속 사용하세요. 브라우저 데이터 삭제 시 기록도 삭제되며 다른 기기에 동기화되지 않습니다.
